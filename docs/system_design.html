Overview

The repository has two halves that meet at one artifact — the trained model weights. The research plane (repo root: src/, notebooks/, scripts/) is the thesis work that prepares data, trains and evaluates computer-vision models. The product plane (app/) is the mobile app + API that serve those models to end users. This page shows the high-level design and how data flows across the whole system.

research / offline (ML) client (mobile) product API / ML package GPU cloud (Modal) data / storage

The cannabis_maturity package is deliberately framework-light so the same detector/classifier code runs in three places: research pipelines, the API's local mode, and the Modal GPU worker.

Deployment: for local mode the API reads weights from checkpoints/; for cloud mode app/modal/upload_weights.py pushes them to a Modal volume that the GPU worker mounts at /models.
